Primeira configuração

Faça isso uma vez só. Você vai criar o seu e-mail e senha de acesso ao painel. Para isso, precisa da chave do GitHub (veja como conseguir logo abaixo).

Como conseguir a chave do GitHub
  1. Entre no GitHub com a conta da tabela.
  2. Abra github.com/settings/personal-access-tokens/new.
  3. Em Token name, escreva painel-sv04. Em Expiration, escolha o prazo mais longo.
  4. Em Repository access, marque Only select repositories e escolha tabela-sv04.
  5. Em Permissions → Repository permissions → Contents, escolha Read and write.
  6. Clique em Generate token, copie a chave e cole aqui. Guarde num lugar seguro: ela serve para recuperar a senha.

Edite os campos e toque em Salvar no site. Depois de salvar, o site atualiza em 1 a 2 minutos.

Pessoas com acesso

Crie um acesso para quem também pode editar a tabela (ex.: o líder). Você escolhe uma senha provisória e passa para a pessoa; ela troca no primeiro acesso, em Trocar senha.
